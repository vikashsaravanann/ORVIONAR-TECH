   supporting Apache/Nginx web servers.

Q: How do I update the content?
A: Edit the respective .html files directly using any text editor (VS Code recommended).
   Each page has clear HTML structure for easy modification.

Q: Are the images optimized for web?
A: Yes, all 32 images are WebP format (2.3-2.4KB each) with optimal compression.
   This ensures fast page load times and better user experience.

Q: How do I enable HTTPS?
A: Purchase an SSL certificate from your hosting provider (usually included free).
   Configure it in your server/cPanel/control panel to enable HTTPS.

Q: What if I need to add more pages?
A: Copy any existing page, modify the content, update navigation links in the footer,
   and test locally before deploying.

Q: Can I monitor website performance?
A: Yes, integrate Google Analytics or similar tools by adding tracking code to 
   the <head> section of index.html (or all pages for comprehensive tracking).
