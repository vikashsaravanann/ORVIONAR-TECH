TROUBLESHOOTING
═══════════════

Issue: 404 errors on non-root pages
   Solution: .htaccess not installed or mod_rewrite disabled
   → Upload .htaccess with correct permissions (644)
   → Contact hosting to enable mod_rewrite

Issue: Images not loading
   Solution: Incorrect image paths or assets folder structure
   → Verify assets/ folder in root
   → Check .htaccess MIME type declarations for WebP
   → Verify image file paths in .html files

Issue: CSS/JS not loading
   Solution: Incorrect CSS/JS paths or directory structure
   → Verify css/ and js/ folders in root
   → Check path references in <link> and <script> tags
   → Use relative paths (css/style.css, not /css/style.css)

Issue: Slow page load
   Solution: .htaccess compression not enabled
   → Verify .htaccess includes mod_deflate rules
   → Enable GZIP compression in hosting control panel
   → Use Google PageSpeed Insights for optimization suggestions

Issue: SSL/HTTPS certificate error
   Solution: Install or configure SSL certificate
   → Use free Let's Encrypt from hosting control panel
   → Update .htaccess for HTTPS redirect if needed
   → Test on https://www.orvionar.in/
